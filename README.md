# Fichas de Química

Tres módulos de estudio en una sola app web (sin servidor, funciona sin conexión):

- **Formulación** (`index.html`): 127 compuestos con repaso espaciado, test, clasificación y reglas de nomenclatura.
- **Ácido-base** (`acido-base.html`): fichas de ácidos y bases fuertes y débiles y de pares conjugados (con Ka, Kb y pKa), test generado al azar, problemas de pH con solución paso a paso y teoría.
- **Equilibrio químico** (`equilibrio.html`): ruta de 7 unidades (equilibrio dinámico → Kc → Kp → Q → Le Châtelier → tablas ICE → Ka/Ksp). Cada unidad tiene lección, práctica con preguntas nuevas cada vez (se abre la siguiente con un 70 %), fichas con repaso espaciado y un laboratorio interactivo de Le Châtelier.

Ábrela en Safari y usa **Compartir → Añadir a pantalla de inicio**. Después de abrirla una vez, funciona sin conexión. El progreso se guarda en el propio dispositivo.

Archivos comunes: `estudio.css` (estilos), `estudio.js` (guardado, repetición espaciada, fichas y preguntas), `ab-data.js` y `eq-data.js` (contenido).
